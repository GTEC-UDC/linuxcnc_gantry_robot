# Installation

## Prerequisites

Before building the `calibxyzkins` module, ensure you have:

- LinuxCNC development environment
- Standard build tools (make, gcc)
- LinuxCNC development headers

## Building the Module

Navigate to the module directory and build:

```bash
cd linuxcnc/components/linuxcnc_calibrated_xyz_kins
make
```

The build process will create the `calibxyzkins.so` shared library that can be loaded by LinuxCNC.

## System-wide Installation

To install the module system-wide (optional):

```bash
sudo make install
```

This will copy the module to the system LinuxCNC components directory, making it available to all LinuxCNC configurations on the system.

## Loading the Module

The module can be loaded as any other HAL component. Depending on the machine configuration, the `coordinates` and `kinstype` parameters can be used to specify the axis-to-joint mapping.

### Basic Usage Examples

**Basic usage** (equivalent to `trivkins`):
```hal
loadrt calibxyzkins
```

**Specify coordinate mapping**:
```hal
loadrt calibxyzkins coordinates=xyz
```

**Gantry configuration with duplicated Y axis**:
```hal
loadrt calibxyzkins coordinates=xyyz kinstype=B
```

**6-axis machine** (calibration only applied to X, Y, Z):
```hal  
loadrt calibxyzkins coordinates=xyzabc
```

## Verification

After loading the module, you can verify it's working by:

1. **Check HAL components**:

   ```bash
   halcmd show comp
   ```

   Look for `calibxyzkins` in the component list.

2. **Check HAL parameters**:

   ```bash
   halcmd show param calibxyzkins
   ```

   This will display all available calibration parameters.

3. **Test basic functionality**:

   The module should function identically to `trivkins` when no calibration parameters are set.

## Integration with LinuxCNC Configuration

To use the module in your LinuxCNC configuration:

1. **Replace trivkins** in your HAL file:

   ```hal
   # Replace this:
   # loadrt trivkins coordinates=xyz
   
   # With this:
   loadrt calibxyzkins coordinates=xyz
   ```

2. **Add calibration parameters** (generated by the error analysis system):

   ```hal
   # Set calibration parameters
   setp calibxyzkins.calib-a.xx 0.9990369633
   setp calibxyzkins.calib-a.xy 0.00351911362
   # ... (additional parameters)
   ```

3. **Test the configuration** before applying calibration parameters to ensure basic functionality works.
