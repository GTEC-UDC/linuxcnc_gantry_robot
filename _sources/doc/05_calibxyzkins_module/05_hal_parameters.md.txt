# HAL Parameters

The `calibxyzkins` module exposes numerous HAL parameters for configuring the calibration transformation and controlling the inverse kinematics solver.

## Calibration Matrix A (Linear Terms)

The linear transformation matrix parameters:

| Parameter | Type | Access | Default | Description |
|-----------|------|--------|---------|-------------|
| `calibxyzkins.calib-a.xx` | float | RW | 1.0 | A[1,1] - X linear coefficient for X |
| `calibxyzkins.calib-a.xy` | float | RW | 0.0 | A[1,2] - Y linear coefficient for X |
| `calibxyzkins.calib-a.xz` | float | RW | 0.0 | A[1,3] - Z linear coefficient for X |
| `calibxyzkins.calib-a.yx` | float | RW | 0.0 | A[2,1] - X linear coefficient for Y |
| `calibxyzkins.calib-a.yy` | float | RW | 1.0 | A[2,2] - Y linear coefficient for Y |
| `calibxyzkins.calib-a.yz` | float | RW | 0.0 | A[2,3] - Z linear coefficient for Y |
| `calibxyzkins.calib-a.zx` | float | RW | 0.0 | A[3,1] - X linear coefficient for Z |
| `calibxyzkins.calib-a.zy` | float | RW | 0.0 | A[3,2] - Y linear coefficient for Z |
| `calibxyzkins.calib-a.zz` | float | RW | 1.0 | A[3,3] - Z linear coefficient for Z |

## Calibration Matrix B (Quadratic Terms)

The quadratic transformation matrix parameters:

| Parameter | Type | Access | Default | Description |
|-----------|------|--------|---------|-------------|
| `calibxyzkins.calib-b.xx` | float | RW | 0.0 | B[1,1] - X² coefficient for X |
| `calibxyzkins.calib-b.xy` | float | RW | 0.0 | B[1,2] - Y² coefficient for X |
| `calibxyzkins.calib-b.xz` | float | RW | 0.0 | B[1,3] - Z² coefficient for X |
| `calibxyzkins.calib-b.yx` | float | RW | 0.0 | B[2,1] - X² coefficient for Y |
| `calibxyzkins.calib-b.yy` | float | RW | 0.0 | B[2,2] - Y² coefficient for Y |
| `calibxyzkins.calib-b.yz` | float | RW | 0.0 | B[2,3] - Z² coefficient for Y |
| `calibxyzkins.calib-b.zx` | float | RW | 0.0 | B[3,1] - X² coefficient for Z |
| `calibxyzkins.calib-b.zy` | float | RW | 0.0 | B[3,2] - Y² coefficient for Z |
| `calibxyzkins.calib-b.zz` | float | RW | 0.0 | B[3,3] - Z² coefficient for Z |

## Calibration Vector C (Offset Terms)

The constant offset vector parameters:

| Parameter | Type | Access | Default | Description |
|-----------|------|--------|---------|-------------|
| `calibxyzkins.calib-c.x` | float | RW | 0.0 | C[1] - Constant offset for X |
| `calibxyzkins.calib-c.y` | float | RW | 0.0 | C[2] - Constant offset for Y |
| `calibxyzkins.calib-c.z` | float | RW | 0.0 | C[3] - Constant offset for Z |

## Joint Limits

Joint limit parameters for constraining the inverse kinematics solution:

| Parameter | Type | Access | Default | Description |
|-----------|------|--------|---------|-------------|
| `calibxyzkins.min-limit.x` | float | RW | -∞ | Minimum joint limit for X |
| `calibxyzkins.min-limit.y` | float | RW | -∞ | Minimum joint limit for Y |
| `calibxyzkins.min-limit.z` | float | RW | -∞ | Minimum joint limit for Z |
| `calibxyzkins.max-limit.x` | float | RW | +∞ | Maximum joint limit for X |
| `calibxyzkins.max-limit.y` | float | RW | +∞ | Maximum joint limit for Y |
| `calibxyzkins.max-limit.z` | float | RW | +∞ | Maximum joint limit for Z |

## HAL Pins

### Inverse Kinematics Solver Settings

| Pin | Type | Direction | Default | Description |
|-----|------|-----------|---------|-------------|
| `calibxyzkins.max-iter` | u32 | IO | 10 | Maximum Newton-Raphson iterations |
| `calibxyzkins.tol` | float | IO | 1e-3 | Convergence tolerance |

## Parameter Setting Example

Here's an example of setting calibration parameters in a HAL file:

```hal
# Load the module
loadrt calibxyzkins coordinates=xyz

# Calibration matrix A (linear terms)
setp calibxyzkins.calib-a.xx 0.9990369633
setp calibxyzkins.calib-a.xy 0.00351911362
setp calibxyzkins.calib-a.xz 0.01233976766
setp calibxyzkins.calib-a.yx -0.002370503681
setp calibxyzkins.calib-a.yy 1.002465791
setp calibxyzkins.calib-a.yz 0.003979069254
setp calibxyzkins.calib-a.zx -0.001035471646
setp calibxyzkins.calib-a.zy -0.004752129099
setp calibxyzkins.calib-a.zz 1.000191446

# Calibration matrix B (quadratic terms)
setp calibxyzkins.calib-b.xx 2.205888871e-07
setp calibxyzkins.calib-b.xy -8.883515393e-07
setp calibxyzkins.calib-b.xz 0
setp calibxyzkins.calib-b.yx 3.1221182e-07
setp calibxyzkins.calib-b.yy -4.690445432e-08
setp calibxyzkins.calib-b.yz 0
setp calibxyzkins.calib-b.zx 2.301649573e-07
setp calibxyzkins.calib-b.zy 9.733292478e-07
setp calibxyzkins.calib-b.zz 0

# Calibration vector C (offset terms)
setp calibxyzkins.calib-c.x 9.648396195
setp calibxyzkins.calib-c.y 0.8905471887
setp calibxyzkins.calib-c.z 4.55518685

# Optional: Set joint limits
setp calibxyzkins.min-limit.x 0
setp calibxyzkins.max-limit.x 5000
setp calibxyzkins.min-limit.y 0  
setp calibxyzkins.max-limit.y 5000
setp calibxyzkins.min-limit.z -1000
setp calibxyzkins.max-limit.z 0

# Optional: Adjust solver settings
setp calibxyzkins.max-iter 20
setp calibxyzkins.tol 1e-4
```

## Runtime Parameter Monitoring

You can monitor parameter values during runtime:

```bash
# View all calibration parameters
halcmd show param calibxyzkins

# View specific parameter
halcmd show param calibxyzkins.calib-a.xx

# Monitor solver performance
halcmd show pin calibxyzkins.max-iter
halcmd show pin calibxyzkins.tol
```
